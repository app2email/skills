# app2email webhooks

Create one with `POST /webhooks` (scope `webhooks:manage`). Every webhook gets every event: check the event's `type` and answer 2xx to the ones you do not handle. Events: `message.status`, `message.received`, `message.failed`, `contact.opted_out`, `broadcast.completed`, `usage.threshold`, `template.status_changed`, `conversation.owner_changed`, `message.held_for_approval`, `approval.resolved`, `contact.updated`, `waitlist.joined`, `waitlist.notified`, `waitlist.removed`, `booking.created`, `booking.cancelled`, `booking.rescheduled`, `booking.rated`, `flow.completed`, `booking.updated`, `booking.note.created`, `calendar.block.created`, `calendar.block.deleted`, `call.incoming`, `call.status`, `message.edited`, `message.deleted`, `contact.changed_number`, `number.updated`, `number.error`, `flow.status_changed`, `booking.paid`, `booking.refunded`, `payment.paid`, `package.purchased`, `poll.voted`, `poll.closed`, `booking.customer.erased`, `order.created`, `order.paid`, `order.accepted`, `order.ready`, `order.completed`, `order.cancelled`, `order.refunded`, `order.no_show`, `submission.created`, `submission.files_ready`, `submission.updated`, `submission.status_changed`, `submission.assigned`, `submission.note_added`, `submission.customer_replied`, `submission.deleted`, `submit.automation_failed`, `ticket.order.confirmed`, `ticket.order.refunded`, `ticket.checked_in`, `ticket.passed_on`, `ticket.event.sold_out`, `ticket.event.cancelled`, `ticket.waitlist.joined`, `ticket.buyer.erased`.

Signature: header `X-App2email-Signature: t=<unix seconds>,v1=<hex HMAC-SHA256 of "<t>.<raw body>">` with the webhook's secret (shown once at creation or after `rotate-secret`). While an old secret still signs (`rotate-secret` with `keep_old_for_hours`) the header has two `v1=` values: accept the event when any one matches. Reject deliveries older than 5 minutes. Deliveries are retried with backoff; `GET /webhooks/{id}/deliveries` shows attempts and `POST .../redeliver` sends one again.

Every event with its payload, verify code (Node.js, Python, PHP) and a tester: https://www.app2email.com/docs/api/webhooks
